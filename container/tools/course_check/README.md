# course_check

`code_blocks.py` builds the whole programs of the code blocks of lesson
pages and checks that every failure is one the page shows.
`quiz_answers.py` checks the shape of the lesson questions and proves the
marked answer by building and running the program the question carries.
Both take `--help`, and the manual is
[container/docs/course-checks.md](../../docs/course-checks.md).
